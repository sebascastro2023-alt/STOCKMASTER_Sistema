## 🎯 Objetivo General del Proyecto
Diseñar y desarrollar un sistema integral de gestión de inventarios que permita administrar usuarios, proveedores, categorías, materiales y movimientos de entrada y salida, garantizando control, trazabilidad y seguridad mediante la gestión de roles y permisos.

---

## ✅ Objetivos Específicos
- Analizar los requerimientos funcionales y no funcionales del sistema.
- Diseñar la arquitectura, modelos de datos y diagramas UML.
- Implementar el sistema con tecnologías web y base de datos relacional.
- Documentar el proceso técnico y funcional del proyecto.
- Realizar pruebas para garantizar la calidad y funcionamiento del sistema.
- Implementar mecanismos de seguridad y control de accesos.
- **Evaluar el flujo real de inventario y optimizar procesos administrativos.**

---

## 📦 Alcance del Proyecto
El sistema gestionará:

- Usuarios y roles (administrador, auxiliar, invitado)
- Proveedores
- Categorías
- Materiales
- Entradas y salidas de inventario
- Reportes y registro histórico de movimientos

El desarrollo incluirá:

- Frontend y backend funcional
- Base de datos estructurada y documentada
- Diagrama entidad–relación, clases, despliegue y secuencia
- Manual de usuario básico

No incluye: facturación, conexión a sistemas externos, contabilidad automatizada.
